# FRDO Checker

Приложение для проверки Excel-шаблонов ФРДО по направлениям СПО и ПО.

FRDO Checker помогает быстро найти ошибки заполнения в `.xlsx`, подсветить проблемные строки, открыть нужную ячейку в Excel и применить безопасные автоматические исправления после подтверждения пользователя.

## Возможности

- Проверка всех `.xlsx` в выбранной папке и вложенных каталогах.
- Отдельные профили правил для СПО и ПО.
- Проверка обязательных полей, форматов дат, годов, СНИЛС, ОГРН, КПП и числовых значений.
- Сверка значений со справочниками листа `Проверки`.
- Проверка дублей по документам, СНИЛС и ФИО с датой рождения.
- Проверка структуры шаблона: заголовки, лишние данные за пределами шаблона, скрытые колонки, подозрительная ширина, защита листа `Шаблон`.
- Проверка и восстановление формул в расчетных колонках.
- Цветовая подсветка строк по важности проблемы.
- Фильтры по типу проблемы, профилю, важности и файлу.
- Сортировка таблицы кликом по заголовку.
- Открытие конкретной проблемной ячейки в Excel.
- Ручной редактор ячейки внутри приложения.
- Настройки правил и автокоррекций.
- Отчеты `.doc` по исправлениям и текущей таблице ошибок.
- Создание резервных копий в папке `_bak` перед изменением файлов.

## Быстрый Запуск

Самый простой вариант для Windows:

```text
dist\FRDO_Checker.exe
```

Приложение можно запускать без установленного Python.

При первом запуске выберите папку с шаблонами, нажмите `Проверить`, затем просмотрите найденные проблемы. Автоматические исправления применяются только после подтверждения.

## Запуск Из Исходников

```powershell
python frdo_spo_checker.py
```

Для консольной проверки каталога:

```powershell
python frdo_spo_checker.py --cli .
```

## Как Работает Проверка

Приложение читает книги Excel через `openpyxl`, определяет профиль шаблона и применяет набор правил:

- файлы СПО проверяются по структуре СПО;
- файлы ПО, включая файлы в папке `PO`, проверяются по структуре ПО;
- справочные значения берутся из встроенного листа `Проверки`;
- правила по всем колонкам описаны в [RULE_MATRIX.md](RULE_MATRIX.md).

Ошибки делятся по важности:

- `Блокирующая` - требует исправления перед загрузкой;
- `Предупреждение` - стоит проверить вручную;
- `Автоисправление` - может быть исправлено приложением после подтверждения.

## Автоматические Исправления

Приложение умеет безопасно исправлять:

- лишние пробелы и длинные тире;
- типовые недопустимые символы, если замена однозначна;
- значения справочников, отличающиеся только регистром или форматированием;
- даты и годы, которые можно привести к нужному виду;
- формат СНИЛС, если 11 цифр и контрольная сумма корректны;
- пустую серию документа значением `Нет`, когда это допустимо по правилам;
- условные поля целевого договора и сведений об оригинале;
- снятую защиту листа `Шаблон`;
- затертые формулы в расчетных колонках;
- скрытые колонки;
- списки категорий `C, D, E, F` с разделением на отдельные строки по блокам.

Ошибки без безопасного исправления остаются в списке для ручной проверки. Например, СНИЛС с неверной контрольной суммой не исправляется автоматически, потому что это может быть другой номер.

## Интерфейс

Основной экран рассчитан на работу с большими таблицами ошибок:

- верхняя панель для выбора папки и запуска проверки;
- отдельная панель действий для исправлений, отчетов и настроек;
- фильтры над таблицей;
- таблица с цветовой подсветкой строк;
- нижняя строка деталей с полным текстом выбранной проблемы.

Двойной клик по строке или кнопка `Открыть ячейку` открывает файл Excel на листе `Шаблон` и выделяет проблемную ячейку.

## Отчеты

Доступны два типа отчетов:

- отчет по выбранным автоматическим исправлениям;
- отчет по текущей таблице ошибок с учетом фильтров и сортировки.

Отчеты сохраняются в формате `.doc` и открываются в Microsoft Word. Табличный отчет настроен под печать: альбомная ориентация, компактный шрифт, повтор заголовка таблицы на каждой странице.

## Резервные Копии

Перед сохранением измененного Excel-файла создается резервная копия рядом с исходным файлом:

```text
_bak\имя_файла_ГГГГММДД_ЧЧММСС.xlsx.bak
```

Это позволяет откатиться к исходному состоянию, если правки нужно отменить.

## Настройки

В окне `Настройки правил` можно включать и отключать отдельные проверки и автокоррекции:

- проверку дублей;
- проверку единственного видимого листа `Шаблон`;
- проверку формул;
- проверку структуры колонок;
- проверку защиты листа;
- параллельное чтение файлов;
- отдельные типы автоматических исправлений.

Настройки сохраняются локально в `frdo_checker_settings.json` рядом с приложением. Этот файл не входит в репозиторий.

## Автотесты

```powershell
python -m unittest discover -s tests -v
```

Тесты покрывают настройки, подсказки, автокоррекции, разделение категорий, формулы, защиту листа, резервные копии, отчеты и проверку структуры выпадающих списков.

## Сборка Exe

Сборка выполняется через PyInstaller:

```powershell
pyinstaller FRDO_Checker.spec --noconfirm
```

Готовый файл появляется здесь:

```text
dist\FRDO_Checker.exe
```

## Конфиденциальность

Репозиторий содержит только приложение, тесты и документацию. Рабочие Excel-файлы с персональными данными не должны добавляться в Git. Для этого в `.gitignore` исключены резервные копии, отчеты, локальные настройки, кеши и сборочные временные файлы.

## Важно

FRDO Checker помогает найти технические ошибки и типовые нарушения структуры шаблона, но не заменяет проверку исходных документов. Значения вроде СНИЛС, дат рождения и реквизитов документов нужно сверять с первоисточником.
