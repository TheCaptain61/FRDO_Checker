# Проверка шаблонов ФРДО СПО и ПО

Приложение `frdo_spo_checker.py` проверяет все `.xlsx` в выбранной папке и вложенных папках. Корневые шаблоны СПО проверяются по инструкции для СПО, а файлы с PO-структурой из папки `PO` проверяются по инструкции для ПО от 21.07.2025 и по справочникам, встроенным в скрытый лист `Проверки`.

Подробная матрица правил по всем колонкам находится в `RULE_MATRIX.md`.

## Запуск интерфейса

```powershell
python frdo_spo_checker.py
```

В окне можно выбрать папку, запустить проверку, посмотреть найденные ошибки и применить только выбранные или все автоматические исправления.

Готовый exe находится здесь:

```text
dist\FRDO_Checker.exe
```

Его можно запускать без команды `python`.

Перед сохранением измененного файла приложение создает резервную копию в отдельной папке `_bak` рядом с исходным файлом:

```text
_bak\имя_файла_ГГГГММДД_ЧЧММСС.xlsx.bak
```

## Фильтры и исправления

После проверки можно фильтровать таблицу:

- по типу проблемы: все, только ошибки, только исправимые;
- по профилю: `СПО` или `ПО`;
- по важности: блокирующая, предупреждение, автоисправление;
- по конкретному файлу.

Кнопка `Исправить выбранные` применяет только выделенные строки. Кнопка `Исправить в фильтре` применяет исправимые строки, которые сейчас показаны с учетом фильтров.

Перед применением исправлений появляется окно с файлами и количеством исправлений по каждому файлу. Можно снять галочки с файлов, которые не нужно менять.

В этом же окне есть кнопка `Сохранить отчёт .doc`. Отчёт сохраняется по выбранным галочками файлам и содержит дату формирования, количество файлов, общее количество исправлений и разбивку типов исправлений по каждому файлу.

Кнопка `Отчёт таблицы .doc` сохраняет текущую таблицу ошибок целиком с учетом выбранных фильтров и сортировки: профиль, важность, статус, файл, ячейку, поле, проблему, подсказку, текущее значение и предлагаемое исправление.

Строки подсвечиваются цветом:

- красный фон - блокирующие ошибки;
- желтый фон - предупреждения;
- зеленый фон - автоматические исправления.

## Консольная проверка

```powershell
python frdo_spo_checker.py --cli .
```

Команда выводит количество найденных проблем и первые 200 строк отчета. Файлы из вложенных папок показываются с относительным путем, например `PO\shablon_po ПК-4.xlsx`.

## Что проверяется

Для СПО:

- наличие листа `Шаблон` и корректность 46 заголовков;
- обязательные поля из инструкции;
- условные поля: СНИЛС/гражданство/формы/финансирование для документов с датой выдачи с 2021 года, целевой договор только при значении `Да`, сведения об оригинале только для `Дубликат`;
- значения из выпадающих справочников скрытого листа `Проверки`;
- форматы дат, годов, СНИЛС с контрольной суммой, ОГРН, КПП;
- длина и допустимые символы в основных текстовых полях;
- год поступления/окончания и срок обучения.

Для ПО:

- наличие листа `Шаблон` и корректность 35 заголовков;
- обязательные поля по инструкции ПО;
- серия/номер документа, если документ не `Справка об обучении`;
- поля СНИЛС/гражданство/форма/финансирование/форма получения образования для документов с датой выдачи с 2021 года;
- сведения об оригинале только для статуса `Дубликат`;
- поле `Номер документа для изменения` должно оставаться пустым;
- значения из справочников: вид документа, статус, подтверждения, программа ПО, профессия/должность, разряд/класс/категория, пол, гражданство, форма обучения, финансирование, форма получения образования;
- даты, годы, СНИЛС с контрольной суммой;
- срок обучения ПО в часах: число не менее 6;
- списки водительских/тракторных категорий в поле `Присвоенный квалификационный разряд, класс, категория (при наличии)`: например `C,D, E, F` и `C,E,F`, если каждая категория есть во встроенном справочнике;
- длина и допустимые символы в основных текстовых полях.

## Что исправляется автоматически

- лишние пробелы и длинные тире в текстовых значениях;
- типовые недопустимые символы, если их можно безопасно заменить или удалить без потери смысла;
- значения справочников, отличающиеся только регистром или форматом;
- даты, которые можно однозначно привести к `дд.мм.гггг`;
- годы и срок обучения, если годы заполнены корректно;
- формат СНИЛС при корректных 11 цифрах и контрольной сумме;
- очистка полей целевого договора, если `Наличие договора о целевом обучении` = `Нет`;
- очистка сведений об оригинале, если `Статус документа` = `Оригинал`.
- очистка поля `Номер документа для изменения` в PO-шаблонах.
- разделение списков категорий на отдельные строки блоками, как в `ФРДО Свидетельства 24.2.xlsx`: сначала все строки с `C`, затем копии этих строк с `D`, затем с `E`, затем с `F`.
- подстановка `Нет` в пустую серию документа, если серия обязательна, но отсутствует.

Для ФИО приложение также пытается заменить похожие латинские буквы на кириллические, например `A`, `C`, `E`, `O`, `P`, если после такой замены значение становится допустимым. Если безопасное исправление невозможно, ошибка остаётся ручной.

## Проверка дублей

Приложение ищет дубли по всем проверяемым файлам:

- для СПО: серия+номер документа, СНИЛС, ФИО+дата рождения;
- для ПО: серия+номер+категория, СНИЛС+категория, ФИО+дата рождения+категория.

Категория учитывается в PO, чтобы не считать ошибкой правильные повторяющиеся строки `C`, `D`, `E`, `F`.

Ошибки без безопасного исправления остаются в списке для ручной правки в Excel.

## Улучшения интерфейса

- Повторяющиеся сообщения по одной и той же ячейке объединяются.
- В таблице показываются профиль шаблона и важность проблемы.
- По клику на заголовок таблицы строки сортируются по выбранной колонке; повторный клик меняет направление сортировки.
- Кнопка `Открыть ячейку` и двойной клик по строке открывают файл Excel на листе `Шаблон` и выделяют конкретную ячейку ошибки. Если Excel недоступен, файл открывается обычным способом.
- Кнопка `Править ячейку` открывает редактор выбранной ячейки прямо в приложении. Для справочных полей предлагается выпадающий список значений из листа `Проверки`; перед сохранением создаётся `.bak`-копия в папке `_bak`.
- Редактор ячейки проверяет типовые форматы до сохранения: даты `дд.мм.гггг`, годы, часы, числовые поля и СНИЛС с контрольной суммой.
- Для ручных ошибок добавлена колонка `Подсказка`: в ней указано, где искать допустимое значение или какой формат нужен.
- После применения исправлений приложение сразу выполняет повторную проверку и показывает сравнение количества проблем до/после.
- Кнопка `Настройки правил` позволяет включать и отключать отдельные проверки и автокоррекции. Настройки сохраняются в `frdo_checker_settings.json` рядом с приложением.
- Проверка больших каталогов ускорена параллельным чтением файлов. Это можно отключить в настройках.
- Интерфейс обновлён в спокойном рабочем стиле: выделенная панель действий, более читаемая таблица, строка состояния и единая цветовая схема.
- Окно адаптировано под широкий экран около `1884x993`: при запуске открывается почти во весь экран, кнопки действий вынесены в отдельную строку, таблица получила горизонтальную прокрутку, а полный текст выбранной ошибки показывается в нижней панели деталей.
- Профиль файла определяется при основном чтении книги, без дополнительного открытия файла.
- Правила СПО и ПО разделены внутренними профилями, чтобы проще добавлять новые шаблоны.

## Настройки правил

В настройках можно отключить:

- проверку дублей по всем файлам;
- строгую проверку единственного видимого листа `Шаблон`;
- проверку затёртых формул в расчетных колонках;
- автоматическое восстановление затёртых формул по ближайшей формуле в той же колонке с переводом ссылок на нужную строку;
- проверку структуры колонок: лишние данные за пределами шаблона, скрытые колонки, подозрительную ширину, отличия в проверках данных/выпадающих списках;
- проверку защиты листа `Шаблон`;
- параллельное чтение файлов для ускорения больших каталогов;
- отдельные типы автокоррекций: пробелы, значения справочников, даты/годы, СНИЛС, недопустимые символы, очистку условных полей, включение защиты листа `Шаблон`, разделение водительских категорий.

Автоисправление защиты листа включает стандартную защиту листа `Шаблон` без пароля, чтобы не заблокировать пользователю ручную работу с файлом.

Если автокоррекция отключена, сама ошибка не исчезает: она остаётся в списке как ручная и получает подсказку.

## Автотесты

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют сохранение настроек, подсказки для ручных ошибок, отключение автокоррекции недопустимых символов, блочное разделение категорий `C, D, E, F`, проверку формул/защиты, восстановление формул, показ скрытых колонок, автоисправление защиты листа и ручную запись значения с созданием резервной копии.
