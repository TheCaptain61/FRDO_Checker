## Общие требования инструкций

- Вся информация должна находиться на одном листе `Шаблон`; дополнительные листы в файле шаблона не допускаются.
- После заполнения и проверки обязательных полей файл должен быть сохранен как книга Excel `*.xlsx`.
- Красные поля в инструкциях обозначены как обязательные.
- Значения справочных полей должны выбираться из выпадающих списков.
- Статус документа проверяется по классификатору `Оригинал` или `Дубликат`.
- Поля сведений об оригинале заполняются только при статусе `Дубликат`.
- Для дат используется формат `дд.мм.гггг`.
- Для СНИЛС указан формат `ххх-ххх-ххх хх`, объем 14 символов.

## Требования СПО, важные для чекера

- `Год поступления`:
  - не ранее 1978 для `Оригинал`;
  - не ранее 1955 для `Дубликат`;
  - не больше текущего года;
  - формат `гггг`.
- `Год окончания`:
  - не меньше года поступления;
  - не больше текущего года;
  - формат `гггг`.
- `Срок обучения, лет`:
  - рассчитывается по годам поступления и окончания;
  - может быть 0.
- Поля договора о целевом обучении заполняются только если `Наличие договора о целевом обучении = Да`; иначе должны быть пустыми.
- Поля оригинала документа обязательны только для `Дубликат`.

Отдельное практическое правило из ошибок ФРДО: год в `Дата выдачи` не должен быть меньше `Год окончания`. Это уже добавлено в чекер как блокирующая проверка.

## Требования ПО, важные для чекера

- `Год начала обучения`:
  - не ранее 1978 для `Оригинал`;
  - не ранее 1955 для `Дубликат`;
  - не больше текущего года;
  - формат `гггг`.
- `Год окончания обучения`:
  - не меньше года начала обучения;
  - не больше текущего года;
  - формат `гггг`.
- `Срок обучения, часов`:
  - целое число часов;
  - не менее 6 часов.
- `Присвоенный квалификационный разряд, класс, категория`:
  - необязательное поле при отсутствии информации;
  - выбирается из справочника;
  - если введено несколько категорий через запятую/точку с запятой, программа заменяет их на одно значение справочника при однозначном соответствии; иначе показывает блокирующую ошибку и просит выбрать одно значение из выпадающего списка.
- Поля оригинала документа обязательны только для `Дубликат`.
- `Номер документа для изменения` должен оставаться пустым.

Отдельное практическое правило из ошибок ФРДО: год в `Дата выдачи документа` не должен быть меньше `Год окончания обучения`. Это уже добавлено в чекер как блокирующая проверка.

## Руководства оператора СПО и ПО

Оба руководства описывают одинаковый пользовательский поток:

- в разделе пакетов документов нужно скачать шаблон;
- шаблон скачивается в формате `xlsx`;
- заполненный шаблон подписывается электронной подписью поставщика данных;
- при создании пакета нужно выбрать и загрузить подписанный файл;
- система имеет статусы пакетов, включая `Ошибки в документах`, `Невалидный файл`, `Ошибка публикации`, `Неверное название пакета или имя файла`;
- для исправления загруженного пакета предусмотрена операция перезагрузки файла.

Вывод для чекера: локальная проверка должна предотвращать прежде всего ошибки структуры, обязательности, форматов, справочников и межполейных связей до подписания и загрузки файла.

## Уже покрыто текущим чекером

- Поиск `.xlsx` и пропуск временных файлов Excel.
- Пропуск `_bak`, `_merged`, `__merged` и файлов `frdo_merged_*`.
- Определение профиля СПО/ПО.
- Проверка листа `Шаблон`, заголовков, структуры колонок, выпадающих списков и скрытого листа `Проверки`.
- Проверка обязательных полей.
- Проверка справочников и форматных отличий.
- Проверка дат, годов, СНИЛС, длин, запрещенных символов.
- Проверка отношений год начала/поступления <= год окончания.
- Проверка год даты выдачи >= год окончания.
- Проверка условных полей договора о целевом обучении для СПО.
- Проверка полей оригинала только при статусе `Дубликат`.
- Проверка `Номер документа для изменения` для ПО.
- Разделение водительских категорий `C/D/E/F` в любых комбинациях.
- Безопасное объединение файлов без блокирующих ошибок.

## Что стоит проверить глубже следующим шагом

- Точность справочников и именованных диапазонов после обновлений шаблонов 2026 года.
