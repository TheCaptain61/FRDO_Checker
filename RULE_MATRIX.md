# Матрица правил проверки ФРДО СПО и ПО

Документ фиксирует правила по каждой колонке шаблонов и показывает, насколько они покрыты текущим приложением `frdo_spo_checker.py`.

Обозначения:

- `Полное` - правило инструкции покрыто программной проверкой.
- `Частичное` - проверяется основная часть, но есть нюансы, которые не формализованы полностью.
- `Нет` - правило пока не проверяется или проверяется только косвенно.
- `Авто` - приложение может исправить значение после подтверждения пользователя.
- `Ручн.` - нужна ручная правка в Excel.

## Общие правила

| Правило | СПО | ПО | Покрытие | Комментарий |
|---|---:|---:|---|---|
| Файл `.xlsx` | Да | Да | Полное | Приложение сканирует `.xlsx`, временные `~$` пропускаются. |
| Лист `Шаблон` | Да | Да | Полное | Проверяется наличие листа. |
| Один видимый лист с данными | Да | Да | Частичное | Проверяется, что видимый лист один и называется `Шаблон`; скрытый лист `Проверки` используется как справочник. |
| Заголовки шаблона | 46 колонок | 35 колонок | Полное | Проверяется порядок и текст заголовков. |
| Справочники из листа `Проверки` | Да | Да | Полное | Проверка идёт по именованным диапазонам внутри книги. |
| Лишние пробелы/длинное тире | Да | Да | Авто | Текст приводится к нормальному виду. |
| Дубли | Да | Да | Частичное | СПО: серия+номер, СНИЛС, ФИО+дата рождения. ПО: те же ключи с учётом категории. |

## Строгая матрица покрытия

Эта секция фиксирует более строгую трактовку покрытия. Колонка считается `Полное` только если одновременно выполняются все применимые пункты:

- проверяется обязательность или условная обязательность;
- проверяется формат, длина и допустимые символы, если они заданы инструкцией;
- проверяется справочник из листа `Проверки`, если для поля есть выпадающий список;
- проверяются межколоночные условия, если инструкция связывает поле с датой выдачи, статусом документа, оригиналом/дубликатом, целевым договором или типом программы;
- автокоррекция есть только там, где значение можно восстановить однозначно, иначе ошибка остаётся ручной;
- правило описано в этой матрице и покрыто хотя бы одним автотестом или проверяется реальным CLI-сканом.

Если хотя бы один пункт не формализован, статус остаётся `Частичное`, даже если базовая проверка уже есть.

| Блок | СПО | ПО | Строгий статус | Комментарий |
|---|---|---|---|---|
| Заголовки, лист `Шаблон`, рекурсивный поиск `.xlsx` | Да | Да | Полное | Строгая проверка единственного видимого листа регулируется настройкой. |
| Обязательные поля | Да | Да | Полное | Базовые и условные обязательные поля проверяются по профилю. |
| Справочники листа `Проверки` | Да | Да | Полное | Форматные отличия можно исправлять автоматически; настройка может перевести их в ручные ошибки. |
| Даты и годы | Да | Да | Полное | Формат, диапазоны и связи начала/окончания проверяются; однозначные форматы приводятся автоматически. |
| СНИЛС | Да | Да | Полное | Проверяются 11 цифр, формат и контрольная сумма; форматирование можно отключить настройкой. |
| Недопустимые символы | Да | Да | Полное | Безопасные замены предлагаются автоматически; невозможные случаи остаются ручными с подсказкой. |
| Дубли | Да | Да | Полное | СПО и ПО используют разные ключи; проверку можно отключить в настройках. |
| Условная очистка полей | Да | Да | Полное | Лишние поля оригинала/целевого договора/AI очищаются только после подтверждения; можно отключить настройкой. |
| Водительские категории `C, D, E, F` | Нет | Да | Полное для ПО | Списки категорий разделяются блоками строк, как в эталонном файле `ФРДО Свидетельства 24.2.xlsx`. |
| Формулы расчетных колонок | Да | Да | Полное | Если в заполненных строках колонки обнаружена формула, остальные заполненные строки этой колонки проверяются на её сохранность; затёртая формула может быть восстановлена по ближайшей формуле с переводом ссылок на нужную строку. |
| Структура колонок шире заголовков | Да | Да | Полное | Проверяются лишние данные за пределами шаблона, скрытые колонки, подозрительная ширина и отличия в проверках данных/выпадающих списках между строками. |
| Защита листа `Шаблон` | Да | Да | Полное | Снятая защита листа показывается отдельной проблемой и может быть автоисправлена включением защиты без пароля; проверку и автокоррекцию можно отключить в настройках. |
| Параллельная проверка больших каталогов | Да | Да | Полное | Файлы сканируются в несколько потоков, дубли собираются параллельно по файлам и объединяются после чтения. |
| Интерактивная ручная правка | Да | Да | Полное | Выбранную ячейку можно исправить из приложения; для справочных полей подтягиваются значения листа `Проверки`; создаётся `.bak`. |
| Семантическая связка программы, профессии и категории | Нет | Да | Частичное | Справочники проверяются, но смысловая совместимость между J/K/L/M пока не доказывается отдельным правилом. |
| Автооткрытие ячейки в Excel | Да | Да | Полное | Работает через Excel COM в Windows, при недоступности Excel открывается файл. |
| Подсказки по ручным ошибкам | Да | Да | Полное | Подсказка строится по типу ошибки и не меняет данные. |
| Настройки правил | Да | Да | Полное | Настройки сохраняются в `frdo_checker_settings.json`; отключённые автокоррекции становятся ручными ошибками. |
| Автотесты | Да | Да | Частичное | Добавлены тесты на настройки, подсказки, отключение автозамены символов, разделение категорий, формулы/защиту и ручную запись. Нужны дополнительные fixture-тесты на полные СПО/ПО-книги. |
